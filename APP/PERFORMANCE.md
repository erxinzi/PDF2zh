# 性能与翻译质量

PDF 翻译包含解析、版面识别、术语提取、正文翻译、排版和文件生成。APP 在任务详情和日志中显示阶段与耗时，方便区分本地处理和远程模型请求。

## CUDA

GPU 用于版面模型推理。可在“设置 · 内核”中选择自动、CPU 或 CUDA；CUDA 不可用时按当前模式回退至 CPU。

CUDA 组件与 GPU 运行缓存保存在程序自身的 core 目录，不向系统环境安装。GPU 无法缩短远程模型的响应时间，因此整体速度还受 API 延迟和服务限额影响。

## QPS 与并发

- QPS 控制每秒请求数量，并发控制同时等待响应的工作数量。
- 并发设置为 0 时跟随 QPS；“优化并发”只调整并发数量。
- 模型、思考强度、提示词、术语提取、富文本和 OCR 设置不会随并发预设改变。

自动术语提取会在正文翻译前分析文本并请求模型生成术语表。它有助于保持术语一致，也会增加远程请求耗时。是否启用由翻译设置决定。

## 排队、缓存与输出

文档按任务队列执行，单篇文档内可并发请求。仅生成所选输出格式需要的文件，不同任务使用独立配置和工作目录。

暂停和继续保留当前任务状态。任务完成后可在历史任务中查看输出、阶段耗时及质量警告；永久失败的段落、术语提取错误和检测到的空字形会显示在任务详情中。
